# User Guide

1. Open **Platforms** and review each platform's mode. Public-only means discovery may work but login/send automation is not available.
2. Create a campaign. Use dry-run for learning; dry-run messages cannot be approved or sent.
3. Discover candidates or import a bounded reviewed list. Open **Data quality** before relying on sparse profiles.
4. Review candidate match factors, qualification, duplicate warnings, and source links.
5. Generate drafts. Edit every message and remove unnecessary care/health details.
6. Approve messages individually or use bounded bulk approval with the displayed acknowledgements.
7. Send manually in the provider UI. Record the external id/URL or a detailed confirmation; do not record success if the result is ambiguous.
8. Record responses in **Responses**. Negative/unavailable replies stop follow-ups.
9. Use **Follow-ups** for due suggestions and separate approval.
10. Use **Audit**, queue views, campaign ledger, and **Operations** for exceptions and recovery.

Use the Operations pause immediately when a provider changes behavior, a credential may be compromised, duplicate sends are suspected, or personal data is being processed incorrectly.
